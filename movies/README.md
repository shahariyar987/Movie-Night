# Movies folder

Drop any video file you legitimately own into this folder (`.mp4`, `.webm`,
`.ogg`, `.mov`, or `.m4v` — these are the formats browsers can play
natively). It'll automatically show up in the "Movies on this server"
dropdown in the app for anyone in the room to pick.

Nothing else is needed — no restart required, just refresh the page after
adding a file.

Files placed here are NOT committed to git (see `.gitignore`) — this
README is the only thing in this folder that's tracked.
